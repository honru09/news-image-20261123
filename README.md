## How it works

`main.py` (Python 3, standard library only) copies the pre-built `entry.png` to `/output/entry.png` after validating its PNG magic bytes. The output is a byte-for-byte copy of the committed image, so repeated runs are identical. No network, no randomness, no clock reads.

```sh
python3 main.py   # writes /output/entry.png
```
